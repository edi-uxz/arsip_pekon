## 📌 Deskripsi Proyek
**Web Arsip Pekon (E-Surat)** adalah aplikasi manajemen administrasi dan kearsipan berbasis web yang dirancang untuk modernisasi pelayanan publik di tingkat desa/pekon. Sistem ini berfungsi sebagai platform tata kelola surat-menyurat digital yang memungkinkan pengarsipan dokumen resmi, pembuatan surat keterangan warga, serta pemantauan status permohonan secara terpusat yang **dapat diakses secara aman kapan saja dan di mana saja**.

## ✨ Fitur Utama
- **Manajemen Digital E-Surat:** Pembuatan, pencetakan, dan pengarsipan surat masuk/keluar otomatis berbasis templat resmi.
- **Aksesibilitas Multi-Platform:** Sistem terintegrasi berbasis web yang dapat diakses secara fleksibel dari berbagai perangkat (desktop/mobile).
- **Pencarian Arsip Cepat:** Indeksasi data warga dan dokumen untuk pencarian pencatatan administrasi secara instan.
- **Keamanan & Validasi Data:** Operasi pengelolaan data terstruktur (CRUD) guna menjaga kerahasiaan dokumen kependudukan.

## 🛠️ Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend & Styling:** HTML5, CSS3 / Tailwind CSS, JavaScript
- **Web Server:** Apache (XAMPP)
